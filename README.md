# Iris-dataset
Iris dataset-i 3 fərqli çiçək növünə (setosa, versicolor, virginica) aid 150 nümunədən ibarət klassik maşın öyrənməsi datasetidir. Hər bir çiçək çanaq və ləçək yarpaqlarının uzunluğunu və enini ölçən 4 ədədi xüsusiyyətlə  xarakterizə olunur. Təsnifat alqoritmləri və data analizi üçün geniş istifadə edilir.
